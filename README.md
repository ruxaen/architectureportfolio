# Portfolio Book

A premium architectural portfolio presented as an interactive physical book.
Next.js (App Router) + TypeScript + [page-flip](https://github.com/Nodlik/StPageFlip), static-export ready.

The book is the entire interface: no navbar, no sections — just the object, a page
counter, and controls that appear only when they matter (CV → download, contact → icons).

## Run it

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # static export into ./out
```

## Use your own portfolio

Everything lives in **`lib/portfolio.ts`** — the single source of truth.

1. **Pages** — export each portfolio page as an image (WebP/AVIF) into
   `public/portfolio/`, then list them in order in `PAGES`:

   ```ts
   export const PAGES: PortfolioPage[] = [
     { src: '/portfolio/cover.webp', label: 'Portfolio cover', kind: 'cover' },
     { src: '/portfolio/page-01.webp', label: 'Contents' },
     // ...
     { src: '/portfolio/cv.webp', label: 'Curriculum vitae', kind: 'cv' },
     { src: '/portfolio/contact.webp', label: 'Contact', kind: 'contact' },
     { src: '/portfolio/back.webp', label: 'Back cover', kind: 'back' },
   ];
   ```

   - One entry per image, in reading order.
   - `kind` marks special pages; everything else is an ordinary page.
     The CV download button and contact icons react to these automatically.
   - Omit `src` for a blank page (handy for placing the CV on its own spread).
   - Keep every image at the same aspect ratio as `PAGE_WIDTH` × `PAGE_HEIGHT`
     (420 × 594 — change both in one place if your format differs).

2. **CV** — drop your PDF at `public/cv.pdf` and adjust `CV_URL` / `CV_FILENAME`.

3. **Contacts** — edit the `CONTACTS` array (email, LinkedIn, GitHub, Behance,
   Instagram, ...). Icons are inline SVGs in `components/icons.tsx`.

The placeholder artwork currently in `public/portfolio/` was generated by
`npm run generate:pages` (requires `sharp`, a dev dependency). Replace the files
with real exports and delete the script whenever you like.

## Tuning knobs (all in `lib/portfolio.ts`)

| Constant | What it does |
| --- | --- |
| `PAGE_WIDTH` / `PAGE_HEIGHT` | Page ratio for the whole book |
| `MIN_PAGE_WIDTH` / `MAX_PAGE_WIDTH` | On-screen size limits |
| `LANDSCAPE_MIN_STAGE_W` | Stage width below which the book goes single-page |
| `PRELOAD.behind / ahead` | How many pages around the current one stay eager |
| `FLIP_DURATION` | Page-turn animation time (ms) |
| `CONTACTS`, `CV_URL` | See above |

## How the book works

- `components/PortfolioBook.tsx` mounts page-flip in `stretch` + `autoSize` mode,
  so **all responsiveness is CSS** on `.book-host` (`app/globals.css`) — the library
  handles two-page ↔ single-page switching and window resizes itself.
- Page images stay `loading="lazy"` until they come within `PRELOAD` of the current
  spread; then they're promoted to eager/high priority.
- The live book box is published as `--book-w` / `--book-h` on `:root`, so the
  floating controls (prev/next, CV download, contact icons) anchor to the physical
  book instead of guessing viewport positions.
- Keyboard: ←/→ turn pages. `prefers-reduced-motion` shortens flips and UI fades.

## Structure

```
app/            layout, page, globals.css
components/     PortfolioBook, BookExperience, BookControls, PageCounter,
                CVDownloadButton, ContactLinks, FullscreenButton, FloatControl, icons
hooks/          useFullscreen, usePrefersReducedMotion
lib/portfolio.ts   pages, geometry, contacts, CV — single source of truth
public/         portfolio/*.webp, cv.pdf
scripts/        generate-pages.mjs (placeholder artwork only)
types/          page-flip.d.ts (the package ships no types)
```
